# 🦁 XXD Panel 066

### Use relaxed black lines and soft flat paint to tell a childlike and restrained photo story

<a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · <a href="README.ja.md">日本語</a> · <a href="README.ko.md">한국어</a> · <a href="README.ar.md">العربية</a>

Panel 066 retains the most memorable subject relationships and a few environmental clues in the photo, using slightly awkward black lines, 3–6 pastel color blocks and handwritten observation sentences to form a professionally edited freehand drawing.

**Keywords:** Childlike narrative · Clumsy black line · Soft flat painting · Healing color · Handwritten observation

## Use

```text
/xxd-panel-066 photo.jpg --mode design-only --size 3:4 --text prompt --locale en-GB
```

Supports single image, directory batch, four output modes, multiple sizes and three text modes. See [SKILL.md](SKILL.md) for the complete behavior.
