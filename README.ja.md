# 🦁 XXD Panel 066

### リラックスした黒の線と柔らかいフラット ペイントを使用して、子供らしく抑制された写真のストーリーを伝えます

<a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · <a href="README.ja.md">日本語</a> · <a href="README.ko.md">한국어</a> · <a href="README.ar.md">العربية</a>

Panel 066 は、最も記憶に残る被写体の関係性と環境に関するいくつかの手がかりを写真に残し、少しぎこちない黒い線、3 ～ 6 個のパステル カラー ブロック、手書きの観察文を使用して、プロが編集したフリーハンドの図面を作成します。

**キーワード:** 子供っぽい物語 · ぎこちない黒い線 · 柔らかな平面絵 · 癒しの色彩 · 手書きの観察

## 使用する

```text
/xxd-panel-066 photo.jpg --mode design-only --size 3:4 --text prompt --locale ja-JP
```

単一画像、ディレクトリ バッチ、4 つの出力モード、複数のサイズ、および 3 つのテキスト モードをサポートします。完全な動作については、[SKILL.md](SKILL.md) を参照してください。
